# Управление озвучкой, уборка после установки, акустика оригинала, лёгкая студия

Четыре ограниченные доработки существующих потоков (подпроекты B–E из спецификации конвейера
голоса v2). Решения приняты пользователем 2026-11-08; каждая часть реализуется по тестам.

## D. Пауза и «Остановить и удалить озвучку»

- `DubJobs.pause_flag` (Event). `pause(gid)` / `resume(gid)` действуют на текущую задачу.
  Длинные циклы (озвучка, контролёр, пробы, подготовка между стадиями) вызывают
  `self._checkpoint()`: при паузе ждёт, при отмене возвращает True. Обучение тембра (подпроцесс
  Applio) на паузу не ставится — пауза срабатывает между персонажами.
- `stop_delete(gid)`: отмена + флаг `purge`. Задача озвучки ведёт список `produced` — реплики,
  получившие файл в этом запуске. После завершения задачи рабочий поток (`_run`) при флаге
  `purge` удаляет их файлы и возвращает реплики в «ждут озвучки»; ранее озвученные и одобренные
  реплики не трогаются. Сообщение: «Остановлено, озвучка этого запуска удалена (N реплик)».
- API: `POST /projects/{gid}/pause`, `/resume`, `/stop-delete`; `status.paused`.
- Студия: во время озвучки/контроля — кнопки «⏸ Пауза» / «▶ Продолжить» и
  «■ Остановить и удалить озвучку»; у остальных задач — «⏸ Пауза» и «■ Стоп», как раньше.

## C. Уборка после установки («Минимум»)

- Настройка `after_install`: `minimum` (по умолчанию) | `keep`. При `minimum` после удачной
  установки удаляются `orig/`, `orig_chunks/`, `samples/`, `bench/` (и прежний мусор).
  Остаются `project.db` (переводы, оценки), `gen/` (готовая озвучка — для переустановки и
  экспорта), `backup/` (для «Удалить озвучку»), `voices/` (модели тембра), `profiles/`.
- Проект помечается `originals_purged: {at, bytes}`. Кнопки «Оригинал» и переозвучка без
  оригиналов недоступны; в студии — строка «Оригиналы удалены (N ГБ) — вернуть» с кнопкой,
  которая запускает извлечение заново (`extract` поверх существующего проекта: реплики и
  переводы не сбрасываются). Задачи, которым нужны оригиналы (озвучка, контролёр, пробы),
  сами ставят извлечение перед собой.
- В карточке установки — оценка, сколько освободится.

## B. Смех, кашель, вздохи и эхо из оригинала

- Стыки: вклеенные куски оригинала (края и внутренние события) получают кроссфейд 12 мс с
  обеих сторон (сейчас внутренние — только затухание самого куска), русская речь выравнивается
  по громкости к речевой части оригинала (без событий), а не ко всей реплике.
- Эхо (режим `effects_mode = auto`, новое умолчание): по хвосту оригинала после последнего
  звука измеряется время спада (RT60 по кривой Шрёдера на участке −5…−25 дБ) и доля
  реверберации; если спад ≥ 0,25 с и хвост выше шума, строится импульс (ранние отражения +
  экспоненциально затухающий шум с тем же RT60 и спектральным наклоном хвоста) и
  накладывается на русскую речь с подобранной долей «wet». Уровень фонового шума оригинала
  (тихие паузы) подкладывается под русскую реплику, чтобы паузы не звучали «мёртво».
  `engine`/`dry` — ничего не накладывается; `baked` — как `auto`, но без порога.
- Всё в новом модуле `ruvoice/acoustics.py`; `performance.compose` и `_fit_line` вызывают его.
  Результат пишется в `info.fit.room` (rt60, wet, noise_db) — виден в карточке реплики.

## E. Лёгкая студия

- Полоса шагов 1–5 (Подготовка, Пробы, Озвучка, Проверка, Установка) с состояниями; раскрыт
  только текущий шаг, завершённые — одной строкой с «развернуть», будущие — приглушены.
- «Голоса», «Стенд движков», «Настройки», «Система» — вкладки-инструменты под полосой шагов,
  открываются по клику, по умолчанию скрыты. Железо — чип в шапке.
- Тексты шагов: одно предложение + главная кнопка; подробности за «Подробнее».
- Панель контроля задачи объединяет прогресс и кнопки паузы/остановки (D).
