# RuVoice — русская озвучка для игр

**Версия 1.1.2:** [скачать установщик для Windows x64](https://github.com/berem-git/ruVoice/releases/tag/v1.1.2).
Скачайте `RuVoice-1.1.2-Setup.exe`: он загрузит архив, проверит и распакует
программу, затем установит CUDA из официального репозитория PyTorch. Python входит в ZIP,
модели скачиваются из интерфейса. Подробнее: [RELEASE_NOTES.md](RELEASE_NOTES.md).

**Версия 1.1.0: голос персонажа собирается из трёх ступеней** — русская речь от
донорского русского образца (без акцента), тембр персонажа обученной моделью, подгонка под
оригинал. Сначала слушайте пробы и стенд движков. [Известные ограничения](KNOWN_ISSUES.md).

Программа находит игры на ПК, показывает, есть ли в них русская озвучка и субтитры, и создаёт русскую
озвучку с попыткой сохранить тембр оригинальных персонажей. Обработка идёт локально на видеокарте;
в выпуске для Windows включена NVIDIA CUDA, поддержка AMD требует отдельной установки ROCm.

## Запуск

### Голос персонажа в 1.1.0: произношение отдельно от тембра

Клонирование голоса с английской записи переносило в русскую речь английскую фонетику — отсюда акцент.
Теперь конвейер устроен в три ступени:

1. **Русская речь донорским голосом.** Текст (ударения ruaccent, пунктуация режиссёра) читает движок речи
   от *русского* образца из донорского банка (`ruvoice/donors`: 16 голосов, у каждого подачи «спокойно /
   зло / грустно» одним и тем же голосом). Донор подбирается персонажу по высоте голоса и отпечатку и
   закрепляется — сменить можно на панели «Голоса».
2. **Тембр персонажа.** Главным персонажам (от 2 минут речи и 12 реплик) обучается модель тембра RVC на
   их записях — одна на персонажа на всю игру, поэтому голос не «плавает». Уровни «быстро / обычно /
   долго» = 150 / 300 / 500 эпох. Модель принимается только после контроля на репликах вне обучения:
   тембр должен сделать голос ближе к персонажу, не испортить произношение и не увести высоту — иначе
   персонаж идёт быстрым путём.
3. **Подгонка под оригинал** — как раньше (длина, громкость, звуки оригинала по краям).

Эпизодические персонажи идут быстрым путём: клонирование с записи персонажа (как в 1.0.0, лёгкий
акцент возможен) или, по настройке, донорский голос без тембра. Среды движков (перенос тембра
Applio/RVC, OmniVoice, VoxCPM2) ставятся из «⋯ → Система и ускорение → Среды движков».

**Стенд движков** (панель в студии и `python -m ruvoice.enginebench --game <ID> --variants ru,ru+rvc,ru@en`)
озвучивает закреплённый набор реплик разными вариантами конвейера и показывает произношение (wav2vec2 —
прокси акцента), разборчивость (Whisper), похожесть на персонажа (ECAPA) и живость интонации рядом с
плеерами — по нему выбираются движки.

Кнопка **«Создать 2 пробы»** делает отдельную страницу сравнения оригинала и русского результата.
Она не устанавливает звук в игру. Для CLI:

```powershell
runtime/python/python.exe -m ruvoice.preview --game <ID_из_библиотеки> --count 2
```

Исходная речь размечается по словам. Уверенно распознанные кашель, вздох, смех и другие звуки
между словами сохраняются из оригинала; вставки внутри перевода требуют прослушивания.
Звук поверх английских слов не копируется. Если смех смешан с речью, передаётся инструкция по подаче,
но точное совпадение не гарантируется. Эхо, уже находящееся в записи, нельзя надёжно восстановить
по одной смешанной дорожке: поддерживается применение явно предоставленных фоновой дорожки и
импульса помещения (`src.effect_stems.background`, `impulse`, `wet`, пути внутри проекта).
В настройках нужно указать, накладывает ли эффекты игровой движок или они записаны в файле.
При неопределённых эффектах результат помечается для проверки.

Обнаружение ресурсов работает по расширениям и сигнатурам файлов, без списка названий игр.
Добавлен адаптер обычных ZIP с аудио, включая архивы с переименованным расширением; поддержаны
SRT/VTT/ASS и сопоставление локализаций по ключам. Существующие адаптеры игровых форматов сохранены.
Обнаружить контейнер ещё не означает уметь его распаковать и собрать: закрытые и зашифрованные
форматы требуют соответствующего адаптера. Неоднозначные пары субтитров не выбираются наугад.

- Двойной клик по **`RuVoice.exe`** — откроется окно приложения. Копия программы одна: повторный запуск
  не открывает второе окно, а выводит на передний план уже запущенное (или достаёт его из трея).
- На главном экране карточка игры показывает озвучку RuVoice: где она идёт сейчас — этап и прогресс,
  где уже сделана — сколько реплик готово и установлена ли она в игру.
- `RuVoice.exe` — маленький запускатель (исходник `launcher\RuVoice.cs`): задаёт пути к моделям и
  инструментам и стартует встроенный `runtime\python\pythonw.exe -m ruvoice.main`. После изменений кода
  пересобирать его не нужно; пересборка запускателя — `launcher\build.ps1`.
- Ошибки пишутся в `data\ruvoice.log`.
- Для разработки: `. tools\env.ps1`, затем `python -m ruvoice.main --browser` (откроется в браузере).
  Новые пакеты: `uv pip install --python $env:RUVOICE_PYTHON <пакет>` — но не те, что тянут за собой
  `torch`: PyTorch лежит отдельно в `runtime\accel\<вариант>` (иначе uv поставит второй torch в общую папку).

## Как сделать озвучку

### Движки и форматы ресурсов

Поиск движка использует сигнатуры и структуру файлов, без таблицы названий игр. Среди распознаваемых
семейств: Unity, Unreal, Source/Source 2, Godot, Ren'Py, RE Engine, FromSoftware, Creation Engine,
REDengine, RAGE, CryEngine, Frostbite, Dunia, Anvil, Glacier, RPG Maker, GameMaker, MonoGame,
LÖVE, NW.js, Quake/PK3/PK4 и MPQ. Основания определения показаны в карточке игры.

**Распознанный движок не означает поддержку всех его игр.** В карточке отдельно отмечается:
есть ли адаптер найденного звука, доступна ли только часть ресурсов или нужен новый адаптер.
Общие читатели Wwise/FMOD и отдельных файлов могут работать даже при неизвестном движке.

Добавлены:

- **Godot PCK v1/v2:** чтение и пересборка незашифрованного отдельного PCK с обычными аудиофайлами.
  Встроенные в exe пакеты, новые версии и внутренние сериализованные AudioStream не поддерживаются этим читателем.
- **Ren'Py RPA v2/v3:** чтение, пересборка, восстановление оригинала; индексы читаются без выполнения
  произвольных объектов pickle. Из `.rpy` извлекаются пары `old/new` и диалоги с комментарием оригинала.
  Скомпилированные `.rpyc` и нестандартные защищённые RPA этим читателем не разбираются.
- **ZIP-контейнеры PK3/PK4/IWD/LÖVE/NW:** существующий ZIP-адаптер распознаёт такие расширения по содержимому.

Для новых PCK/RPA читателей установка пересобирает архив с одобренными репликами, сохраняя остальные файлы,
а удаление возвращает побайтную резервную копию. Переводы JSON/CSV/PO и других поддержанных текстовых
форматов находятся и внутри пакетов. Заголовок `.pck` отличает Godot `GDPC` от Wwise `AKPK`.

Справочник доступен через `GET /api/support`. Старый анализ библиотеки автоматически обновляется при
следующем запуске. Изменения исходников не требуют останавливать текущую озвучку; новые читатели и
серверные маршруты полностью загружаются после перезапуска программы.

Описание форматов сверено с [исходниками Godot](https://github.com/godotengine/godot/blob/4.4/core/io/file_access_pack.cpp)
и [загрузчиком Ren'Py](https://github.com/renpy/renpy/blob/master/renpy/loader.py).

1. В карточке игры — **«🎙 Создать русскую озвучку»**, в студии — кнопка **«Подготовка»** (сама она не
   запускается): извлекаются реплики, готовится русский текст (официальные субтитры), делаются **пробы**.
   Пока идёт работа, крестик окна не закрывает программу, а прячет её в **трей** (значок у часов): работа
   продолжается, по окончании всплывёт уведомление; двойной щелчок по значку — открыть окно, меню — «Выйти».
2. **Послушайте персонажей**: слева оригинал, справа русский. «👍 Нравится — озвучить всю игру»,
   «🔁 Попробовать иначе» (другой способ речи, голоса заново не обучаются), «↺ Начать заново».
3. **Озвучка всей игры** → «Прослушать и одобрить»: «✓ Одобрить все хорошие» (по оценке контролёра),
   фильтр «⚠ Нужна доработка», правка текста, «⟳ Заново». **В игру ничего не записывается, пока реплики
   не одобрены и не нажата «Установить».**
4. **Установка**: ставятся только одобренные реплики. «Удалить озвучку» возвращает оригинал.

**Нагрузка на систему** (переключатель в шапке студии: низкая / средняя / полная) — приоритет процессов,
число потоков, размер пачек и паузы между ними; действует сразу, со следующей пачки. Обучение голоса
всё равно занимает видеокарту на время эпохи, поэтому при «низкой» оно просто идёт дольше.

**Один порядок для всех игр.** Озвучивается всё, у чего есть русские субтитры; выбирать персонажей не нужно.
Кто где говорит, программа выясняет сама на подготовке: группы из файлов игры — это часто разговоры, а не люди
(в разговоре с Эммой звучат и Эмма, и Волк), и без этого голос героя собирался бы из чужих реплик. Каждая реплика
получает отпечаток голоса (ECAPA-TDNN); голос, который звучит во многих разговорах, — главный герой (его имя
языковая модель называет по знанию игры), одинаковые голоса разных групп — один NPC; реплики без слов
(«...», «(Спит)») не трогаются. Применяется только надёжная часть; если адаптер знает говорящих точно
(Forza — `Characters.xml`), шаг пропускается. В Sekiro так нашёлся Волк: 614 реплик из 82 разговоров.

⚙ Настройки (словарь имён, «сколько стараться»,
источник текста, расширенные) — свёрнутые панели внизу студии.

### Голос персонажа и контролёр

Движок выбирается автоматически или в настройках. Ниже описаны также дополнительные режимы Qwen:

- **Текст — официальные русские субтитры.** Реплики, у которых русских субтитров нет, остаются с
  оригинальным голосом (их видно в студии как «Нет русских субтитров»). Перевод нейросетью (Qwen3 через
  llama.cpp) включается отдельно в ⚙ Настройки — для реплик без субтитров или для всей игры. Переводчик
  получает предыдущие реплики диалога и карточки персонажей (пол, возраст, манера, ты/вы), которые сам
  составляет по их репликам, плюс словарь имён.
- **Ударения и «ё».** Перед озвучкой текст проходит через `ruaccent` (словарь + нейросеть для омографов).
  Silero получает ударения («+» перед гласной); CustomVoice знаки ударения ломают (в замере CER 0,17–0,86
  против 0,00), поэтому ему достаётся только восстановленная «ё» — её модель читает верно.
  Модели ruaccent (~500 МБ) докачиваются сами в `models\ruaccent`.
- **Режим «на ночь».** Галочка «Сразу озвучить всю игру и установить без прослушивания» в шаге
  «Подготовка»: после подготовки программа сама озвучивает всё, прогоняет контролёр с доработкой и
  устанавливает в игру. Подготовка не запускается сама при открытии студии — только по кнопке.
- **Речь — Qwen3-TTS 1.7B, русское дообучение с ударениями (siriusfreak/qwen3-tts-12hz-1.7b-ru-stress-cf).**
  Для главных персонажей образец — русский донорский клип с расшифровкой (модель подражает его манере, и
  акцента нет); под эмоцию реплики берётся клип того же донора в нужной подаче. Для эпизодических —
  отпечаток (x-vector) с 30-секундного профиля записей персонажа, без подражания английской речи.
  Ударения модель соблюдает (U+0301 после гласной). Альтернативные источники речи: CustomVoice (готовые
  дикторы + инструкция), Silero v5.6 (носители русского, некоммерческая лицензия), OmniVoice (донор, теги
  смеха и вздохов); клонировщики быстрого пути — Qwen-RU, VoxCPM2, OmniVoice.
- **Тембр персонажа — RVC (Applio), одна модель на персонажа.** Главные персонажи (от 2 минут речи и 12
  реплик, порог настраивается, уровень можно переопределить вручную) обучаются на своих записях:

  | Уровень | Записей на персонажа | Эпох |
  |---|---|---|
  | Без обучения | — | все персонажи быстрым путём |
  | Быстро | до 8 мин | 150 |
  | **Обычно** | до 15 мин | 300 |
  | Долго | до 25 мин | 500 |

  Модель весит ~55 МБ. Рядом с каждым уровнем студия показывает, сколько это займёт времени (по скорости
  прошлых обучений на этом компьютере, `data\train_speed.json`). Сдвиг высоты постоянный для персонажа.
- **Хуже не станет.** Шесть реплик персонажа откладываются и в обучение не попадают; после обучения они
  озвучиваются донором без тембра и с тембром. Модель принимается, только если похожесть на персонажа
  выросла, произношение не стало хуже (wav2vec2) и высота голоса осталась в пределах 3 полутонов от обычной.
  Иначе модель помечается слабой, и персонаж идёт быстрым путём (причина видна на панели «Голоса»).
- **Стенд движков** (панель в студии): закреплённый набор ~30 реплик трёх персонажей озвучивается
  выбранными вариантами (`ru`, `ru+rvc`, `silero+rvc`, `ru@en`, `voxcpm@en`…); страница
  `bench\<метка>\index.html` — реплика × вариант с плеерами и метриками. По ней сравниваются движки.
- **Прослушать и одобрить по персонажам.** Реплики озвучиваются персонаж за персонажем (главные первыми); как
  только персонаж готов целиком, в студии появляется карточка «Послушайте и одобрите»: 4 реплики на пробу
  (оригинал/русский), число замечаний контролёра, поле **комментария для нейросети** и две кнопки —
  «Одобрить персонажа» или «Переозвучить с комментарием». Комментарий («медленнее и ниже, спокойнее»,
  «моложе, живее», «ниже на 3 полутона») хранится у персонажа и применяется при каждой его озвучке: для
  запасного CustomVoice — как инструкция целиком, для основной модели — через темп, высоту и выразительность
  (ключевые слова). В режиме «без прослушивания» карточки показываются, но ничего не блокируют.
- **Место на диске** («Система и нейросети»): размеры нейросетей, среды, инструментов, проектов и кэша;
  проекты игр, которых уже нет на диске, помечаются и предлагаются к удалению (и баннером в библиотеке).
- **Отсев по звуку.** Реплики, где по звуку смех, кашель, крик или дыхание, а не речь, остаются в оригинале
  (нейросеть это не воспроизводит), как и текстовые ремарки «(Cough)», «*cheers*».
- **Контролёр качества** (каждая причина — с кодом проблемы и что делать: пропущены слова → повторить синтез
  или разбить фразу; слишком быстро → не ускорять/сократить текст; голос не похож → проверить образец/модель;
  подача не та → другой образец под эмоцию) после озвучки проверяет каждую реплику: распознаёт русскую речь (ошибки текста),
  сравнивает голос с профилем персонажа, эмоцию оригинала и результата, ищет в оригинале смех, кашель,
  вздохи, крик — и помечает слабые реплики «доработать» с причинами. Забракованные реплики тут же
  переозвучиваются с бо́льшим числом вариантов (старая запись соревнуется с новыми), затем проверяются снова.
- **Стабильный голос.** У главных персонажей тембр задаёт одна обученная модель, поэтому голос не меняется
  от реплики к реплике по построению; «русский голос» персонажа для контролёра — фиксированный центр
  отпечатков калибровочных записей. Зёрна случайности детерминированы: повторная озвучка реплики даёт тот
  же результат, «переделать пробы» — другой прогон. Из вариантов выбирается ближайший к центру и самый
  чистый по произношению.
- **Режиссёр.** Перед озвучкой языковая модель смотрит на оригинал (что слышно: эмоция, темп, паузы, смех,
  крик) и соседние реплики и готовит подачу: расставляет пунктуацию (слова не меняет — это проверяется)
  и пишет указание, как играть; оно видно в карточке реплики. Своё указание к реплике можно написать в поле
  под ней («злее, почти крик») — режиссёр переведёт его в подачу, и реплика переозвучится.
- **Звуки оригинала по краям.** Всё, что в оригинале звучит до и после слов, но не является речью — смех,
  вздох, кашель, глоток, вдох, — берётся из оригинала как есть, русская речь ставится между ними; пауза между
  звуком и речью — как у актёра (по оригиналу, от 0,12 до 0,6 с).
- **Произношение и акцент.** Whisper акцент не слышит: он исправляет услышанное по смыслу (проверено — и
  вероятность языка, и уверенность в тексте у чистой и акцентной речи одинаковые). Поэтому контролёр слушает
  ещё и русским распознавателем без словаря (wav2vec2, `models\wav2vec2-large-xlsr-53-russian`), который
  пишет, как слова звучат на самом деле («эдо» вместо «это», «хранитзя»), и называет конкретные слова.
  Из вариантов выбирается самый чистый по произношению; реплика с акцентом переозвучивается по плану, где
  перечислены слова, прозвучавшие не так.
- **Экспорт и импорт озвучки.** «📦 Экспорт» сохраняет готовую озвучку игры в один файл `.ruvoice`
  (`data\exports`, звук в Opus); «📥 Импорт» в библиотеке или студии подставляет её в ту же игру на другом
  компьютере без повторной озвучки.
- **Мусор.** Промежуточные файлы (варианты озвучки, наборы для обучения, старые замеры) убираются при запуске,
  после подготовки и установки; «Система и нейросети» показывает, сколько занимает каждый раздел.
- **Режимы качества**: быстро (1 вариант), обычно (2 варианта, контролёр выбирает лучший),
  тщательно (4 варианта — в 3–4 раза дольше). «Переделать пробы» — другой прогон с другими случайными
  зёрнами; «Начать заново» пересобирает текст и пробы, обученные голоса остаются.

Важно: русская озвучка во всех играх подменяет существующую дорожку (обычно английскую) — в настройках игры
остаётся выбранным тот язык озвучки, который заменили; отдельный пункт «Русский» в меню игры не появляется.

Поддерживаемые игры. **Привязки к конкретным играм в коде нет**: программа распознаёт устройство файлов
(архив движка, звуковая система, формат субтитров) и сама находит в файлах игры всё нужное — ключи
шифрования, файлы озвучки, субтитры. Адаптеры — по движкам и звуковым системам:
- **Wwise в папке игры, любой движок** (Unity, собственные движки): пакеты `.pck`, банки `.bnk`, отдельные
  `.wem` в папке английского языка; язык определяется внутри файлов. Звук пишется в Wwise PCM — его читает
  любая версия Wwise. Установка заменяет файлы с резервной копией.
- **FMOD в папке игры, любой движок** (`.bank`, `.fsb`): голосовые банки — по именам (VO, dialog, языковые
  суффиксы), без подсказок — по звуку (речь или нет). Зашифрованные `.fsb`: ключ восстанавливается по самому
  банку (шифр — разворот бит и XOR повторяющимся ключом, в банке много нулей и известна сигнатура FSB5;
  на Sekiro найден тот же ключ, что публикуют моддеры). Установка пересобирает банк (Vorbis под таблицу FMOD,
  иначе PCM16), поправляет размеры в RIFF/SND/SNDH у банков FMOD Studio и шифрует обратно; оригинал — в
  резервной копии. Так озвучивается и Forza Horizon 5: 62 776 пар строк субтитров программа нашла сама в
  `StringTables\EN.zip/RU.zip` (двоичные таблицы — см. ниже).
- **RE Engine (Capcom: Resident Evil 2/3/7/Village, Devil May Cry 5, Monster Hunter Rise…)**: архивы
  `re_chunk_000.pak` и патчи читаются напрямую (KPKA, сжатие deflate/zstd; имён файлов нет — нужные файлы
  находятся по содержимому). Озвучка — английские файлы Wwise: потоки в пакетах `.pck` и встроенные звуки в
  банках `.bnk` с языком english(us); у пакетов-оглавлений данные берутся из полной копии. Субтитры — файлы
  `.msg` (все языки сразу), сопоставляются с репликами по распознанной речи. Установка — свой патч
  `re_chunk_000.pak.patch_NNN.pak` (пустую заглушку менеджера модов он занимает, удаление её возвращает),
  звук в Wwise PCM, у потоков со стартом в банке банк переключается на «только поток». RE2: 1917 реплик,
  161 минута; сборка патча проверена, запуск игры с ним — ещё нет. Архивы с зашифрованным оглавлением (RE4,
  Street Fighter 6, Dragon's Dogma 2, Monster Hunter Wilds) пока не читаются.
- **FromSoftware (архивы `Data*.bhd/.bdt`, звук FMOD)**: RSA-ключи архивов программа берёт из exe игры (они
  лежат открытым текстом; каждый `.bhd` пробуется всеми найденными ключами), ключ звуковых банков — по самому
  банку, субтитры (FMG «会話»/TalkMsg) — поиском по содержимому архивов, язык — по папке в пути записи.
  Имя потока `v<число>` = id строки субтитров, поэтому текст подставляется точно. На Sekiro: найдены 2 ключа
  архивов из exe, ключ банков, 6529 английских и 6231 русская строка — совпало со старой таблицей 5637 из 5637.
  Установка: банки пересобираются и заменяют оригиналы в `sound\` с резервной копией.
- **Unreal Engine 4/5 со звуком Wwise** (`.pak`, `.utoc/.ucas`). Архивы читаются на чистом Python (PakFile
  v8–11, IoStore UE 4.26–5.6, сжатие Zlib/Oodle, шифрование AES); текст — из `.locres`, словарей и таблиц,
  которые распознаются по устройству файла (сигнатура AVAFDICT, таблицы маркеров событий), персонаж — из
  метки внутри `.wem`, имени события Wwise или папки ассета. Все пары EN/RU идут в пул субтитров, поэтому
  реплики без найденной связи получают текст по распознанной речи. Установка — **отдельный pak-мод**
  `<Проект>\Content\Paks\~mods\RuVoice_P.pak` (собирается `tools\repak`): оригинальные архивы не меняются.
  Подробности — ниже, в разделе «Игры на Unreal Engine».
- **Source**: реплики из VPK, текст из субтитров `closecaption_*.txt`, установка в `<мод>\custom\ruvoice` —
  файлы игры не меняются. Если в одной папке несколько игр, мод выбирается по названию из его `gameinfo.txt`;
  когда у модов одно название (Half-Life 2 и эпизоды после юбилейного обновления), это одна озвучка на весь
  набор: одинаковые реплики берутся один раз и ставятся во все моды.
- **Звук отдельными файлами** (.wav/.ogg/.mp3/.flac/.opus/.wem): большинство самодельных и инди-игр.
  Файлы заменяются, оригиналы хранятся в `data\projects\<игра>\backup` и возвращаются при удалении.
- **Субтитры для любой игры.** Если игра не подписывает, какой звук к какой строке, программа берёт пул пар
  «английская строка → русская» (от адаптера или из файлов игры, в том числе внутри zip: CSV/TSV со столбцами
  языков, русские `.po`, пары файлов en/ru — текстовые по ключам, двоичные по общей таблице «ключ → смещение»
  или по одинаковым строкам-ключам), распознаёт английскую речь и подбирает строку по сказанному; для роликов
  учитываются склейки 2–3 соседних строк. Если русского текста в игре нет вовсе — переводит языковая модель.
- Игры с официальной русской озвучкой (например, Cyberpunk 2077) озвучивать не нужно — студия подсказывает
  включить её в настройках игры.
- Пока не поддерживаются: звук внутри ресурсов Unity (`.resS`/`.resource`), архивы с зашифрованным оглавлением
  (новые игры Capcom), Frostbite, Decima, REDengine, Elden Ring (Wwise внутри зашифрованного `sd.bdt`).
  Программа честно пишет об этом в карточке игры.

### Игры на Unreal Engine

- **Что нужно.** Библиотека Oodle `tools\oodle\oo2core_9_win64.dll` (архивы UE5 почти всегда сжаты Oodle; в
  комплекте, см. `tools\oodle\README.txt`), `tools\repak\repak.exe` для сборки мода (MIT/Apache-2.0),
  `tools\retoc\retoc.exe` для контейнеров IoStore (MIT), vgmstream и Wwise из комплекта. Всё лежит внутри
  папки программы.
- **AES-ключ.** У части игр (например, Black Myth: Wukong) индекс архивов зашифрован. В карточке такой игры
  появляется поле «AES-ключ архивов» — вставьте ключ (64 hex-символа, можно с `0x`, или base64). Ключи для
  популярных игр публикуют сообщества моддеров (FModel, Nexus Mods); программа ключи не содержит и не раздаёт.
  Без ключа карточка честно пишет «нужен AES-ключ».
- **Какой звук берётся.** `.wem` из папки английского языка (`English(en)`, `English(US)`, `en-us`) — это и есть
  озвучка. Текст: Hogwarts Legacy — метка `labl` внутри каждого `.wem` + словари `Localization\WIN64\SUB-*.bin`;
  SILENT HILL 2 — имя банка события (`VO_An_AreYouAfraid_25BF3372` → ключ `Text_25BF3372` в `Dialog.locres`),
  персонаж — папка `VO_<Имя>` ассета в `.utoc`; Black Myth: Wukong — таблица `FUStAkEventMarkerDesc.data`
  (событие → ID реплик и их границы внутри файла → `FUStDialogueDesc.<id>.Content` в `.locres`), говорящий — из
  `FUStDialogueDesc-*.data`; катсцены из нескольких реплик режутся на отдельные строки по маркерам, а при
  установке собираются обратно в один файл. Где текст найти не удалось, его распознаёт Whisper.
- **Куда ставится.** `<Игра>\<Проект>\Content\Paks\~mods\RuVoice_P.pak` (Wukong: `b1\…`, SILENT HILL 2:
  `SHProto\…`, Hogwarts Legacy: `Phoenix\…`). Папка `~mods` и суффикс `_P` дают моду приоритет над архивами
  игры и над другими `_P`-архивами (включая фанатские озвучки, которые лежат прямо в `Paks`). Для замены `.wem`
  достаточно одного `.pak` даже в играх на IoStore (`.utoc/.ucas`): звук Wwise лежит именно в `.pak`.
  Архивы других языков и фанатских озвучек (`…-GV-RU.pak`) при извлечении пропускаются — за оригинал берётся
  английская дорожка.
- **Проверка запуска** (вручную, программа игру не запускает): после «Установить» запустите игру, выберите
  в настройках английскую озвучку (для Wukong — English) и дойдите до одобренной реплики. Если игра не стартует
  или звук пропал — «Удалить озвучку» (удаляется только `~mods\RuVoice_P.pak`), и игра возвращается в
  исходное состояние; проверка файлов в Steam мод не трогает. В играх с античитом (EAC/BattlEye) программа
  предупреждает: pak-мод там может быть заблокирован.

## Менеджер языков

В таблице языков в карточке игры — «Удалить» у ненужного языка: файлы озвучки/видео/текста этого языка
перемещаются в Корзину Windows (можно вернуть, пока Корзина не очищена).

## Ускорение: NVIDIA, AMD, процессор

Сборки PyTorch лежат в `runtime\accel`: `cuda` (NVIDIA), `cpu` (любой компьютер), `rocm` (AMD,
ставится кнопкой в «⋯ → Система и ускорение», ~3–4 ГБ). Нужная выбирается автоматически по видеокарте.

- **NVIDIA**: драйвер 570 или новее.
- **AMD**: официальная сборка ROCm 7.2.1 для Windows — Radeon RX 9000, часть RX 7000, Ryzen AI 300/400/Max;
  драйвер AMD 26.2.2 или новее. Остальные AMD — на процессоре (медленно, но работает).
- Перевод (llama.cpp, сборка Vulkan) работает на видеокартах NVIDIA и AMD без отдельной установки.

## Перенос на другой компьютер

Программа портативная: все пути считаются от папки, где лежит `RuVoice.exe`. Python, PyTorch, модели,
Wwise, ffmpeg, llama.cpp лежат внутри папки. Проверено копированием на другой диск.

1. Скопируйте папку `RuVoice` целиком (папку `cache` можно не копировать — это кэш загрузок).
2. Запустите `RuVoice.exe`. Список игр соберётся заново под новый компьютер.
3. На ноутбуке с AMD: «⋯ → Система и ускорение» → «Установить ускорение AMD» (если видеокарта поддерживается).

Устанавливать ничего не нужно. Что программа берёт из самой Windows: драйвер видеокарты и WebView2
(встроен в Windows 11; если его нет, программа откроется во вкладке браузера). CUDA, Visual C++ и прочее
лежат внутри папки. Без Vulkan (старый драйвер) перевод работает на процессоре.

Проверка переносимости: копия папки на другом диске прошла весь цикл (извлечение → перевод → озвучка →
установка → удаление) и не трогала оригинальную папку.

Wwise внутри папки — только для личного использования; передавать его другим людям лицензия не разрешает.

Озвучка работает только на видеокарте: NVIDIA с 6 ГБ видеопамяти и больше (CUDA) или поддерживаемая AMD
(ROCm: Radeon RX 9000, часть RX 7000, Ryzen AI 300/400/Max — официальные сборки AMD; **RX 6000 — ночные сборки
проекта ROCm/TheRock, неофициально и экспериментально**, проверено сообществом на RX 6800/6900). Процессорного режима нет — без видеокарты
программа открывается, но озвучка недоступна. Железо определяется само, пользователь ничего не выбирает.

Программа сама определяет железо (видеокарта, видеопамять, ОЗУ) и предлагает набор:

| Набор | Когда | Модели | Размер |
|---|---|---|---|
| **Студия** | видеокарта от 32 ГБ (RTX 5090, профессиональные 48 ГБ) | речь Qwen3-TTS + Qwen3 32B Q6 (почти без потерь) + Whisper + контролёр; 5 вариантов реплики | 34,6 ГБ |
| **Ультра** | видеокарта от 24 ГБ (RTX 3090/4090) | речь Qwen3-TTS + Qwen3 32B + Whisper + контролёр; 5 вариантов реплики | 28 ГБ |
| **Максимум** | видеокарта от 14 ГБ | речь Qwen3-TTS + Qwen3 14B + Whisper + контролёр | 18 ГБ |
| **Качество** | видеокарта от 8 ГБ | речь Qwen3-TTS + Qwen3 8B + Whisper + контролёр | 14,3 ГБ |
| **Баланс** | видеокарта 6–8 ГБ | речь Qwen3-TTS + Qwen3 4B + Whisper + контролёр без эмоций | 10,7 ГБ |

Большая видеокарта даёт качество прежде всего через языковую модель: она режиссирует подачу каждой реплики
(пунктуация, как играть), исправляет её по замечаниям контролёра и называет голоса — Qwen3 32B делает это
заметно точнее, чем 14B. На картах от 24 ГБ по умолчанию озвучивается 5 вариантов каждой реплики (вместо 3):
они помещаются в память одной пачкой, а контролёру есть из чего выбрать. Если модель набора ещё не скачана,
работает самая сильная из скачанных, что помещается в видеопамять.

Установка — одна кнопка в «⋯ → Система и ускорение» (или в подсказке при первом запуске): модели
скачиваются с Hugging Face в `models\<имя>` обычными файлами, с прогрессом. Там же можно поставить другой
набор или удалить ненужную модель. При копировании программы на другой ПК модели едут вместе с папкой.

## Панель «Голоса»

Для каждого персонажа студия показывает число реплик, тип голоса, уровень (главный / эпизодический —
можно переопределить), донора (можно сменить и послушать), состояние тембра (обучен / не принят, с
причиной / не обучен) и две реплики оригинала на прослушивание. Изменения действуют на следующую озвучку.

API: `GET /api/projects/<gid>/voices`, `POST …/voices/donor {"char","donor"}`, `POST …/voices/tier
{"char","tier": "train"|"episodic"|"auto"}`, `GET /api/donors`, `POST …/enginebench {"variants": [...]}`,
`POST /api/system/engines/install {"engine": "rvc"|"omnivoice"|"voxcpm"}`.
