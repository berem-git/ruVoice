# RuVoice 1.0.0

Первый переносимый выпуск для Windows x64.

## Как запустить

1. Скачайте **RuVoice-1.0.0-Setup.exe** из Assets релиза.
   Установщик скачает ZIP, проверит SHA-256, распакует программу и
   установит CUDA из официального репозитория PyTorch. Python вручную ставить не нужно.
2. Выберите папку и нажмите «Скачать и установить». Для временных файлов и
   распаковки нужно около 15 ГиБ свободного места. После установки эти временные
   файлы удаляются, остаётся примерно 6 ГиБ плюс модели и проекты.
3. Запустите `RuVoice.exe` из установленной папки. Переносить только этот exe
   без остальных папок нельзя. **Source code** — только исходники.
4. Откройте «⋯ → Система и ускорение», скачайте подходящий набор моделей.
5. Добавьте игру, подготовьте ресурсы и послушайте короткие пробы перед
   созданием озвучки всей игры. В игру устанавливаются одобренные реплики.

В ZIP включены приложение, Python 3.12 и зависимости
Qwen-RU/VoxCPM2 и базовые инструменты работы со звуком. Моделей, игровых файлов,
озвучки Sekiro, пользовательских настроек и личных проектов в нём нет.
CUDA не включена в ZIP: установщик скачивает проверенные версии PyTorch
2.11.0+cu128 и TorchAudio 2.11.0+cu128 с download.pytorch.org.
При ручной установке распакуйте ZIP целиком, запустите «Установить CUDA.cmd»,
затем `RuVoice.exe`. Нужен интернет и несколько дополнительных ГиБ.
Установщик не обходит закрытый доступ GitHub: если репозиторий закрыт,
скачайте ZIP через браузер и положите рядом с Setup.exe.
Для окна приложения нужен Microsoft Edge WebView2; при его отсутствии
программа использует системный браузер. NVIDIA требует совместимого драйвера;
AMD использует отдельную установку ROCm из интерфейса.

## Возможности

- Поиск игр и определение движков по ресурсам и сигнатурам.
- Адаптеры игровых архивов и обычных аудиофайлов; субтитры и официальные
  русские тексты. Реальная поддержка зависит от формата конкретной игры.
- VoxCPM2, Qwen-RU, пробы без установки, прослушивание и одобрение.
- Неизменяемый русский образец голоса на диске и проверка дрейфа для VoxCPM2.
- Ограниченный кэш образцов; неактивные LoRA-адаптеры выгружаются из VRAM.
- Резервные копии ресурсов, установка одобренных записей и восстановление.

## Качество речи

**Сильный акцент, неверные ударения и смена тембра всё ещё возможны.**
Последние пробы с русским эталоном не прошли пользовательскую проверку
на отсутствие акцента. Генерация речи остаётся экспериментальной.
Контролёр качества и показатели похожести не заменяют прослушивание.
Полный список: [KNOWN_ISSUES.md](KNOWN_ISSUES.md).

Wwise Authoring, Oodle, RVC-окружение и веса моделей не распространяются
в этой сборке. Для некоторых адаптеров понадобятся дополнительные инструменты.

## Проверка

Автоматические тесты и проверка чистой переносимой сборки описаны в
`release-manifest.json` внутри ZIP. Целостность скачанного ZIP проверяется
по `SHA256SUMS.txt` из Assets релиза. Установщик также проверяет полный ZIP
перед распаковкой. Основной ZIP укладывается в лимит GitHub на файл.
